# [Русский] - Техническое описание проекта

Данное руководство предназначено для использования в научной работе и презентациях. В нем подробно описываются возможности приложения, его архитектура и интеграция искусственного интеллекта.

## 🌟 Основные функции
- **🔐 Безопасная авторизация**: Интеграция с **Firebase Auth** для входа и регистрации пользователей.
- **👤 Управление профилем**: Хранение данных пользователя (имя, фамилия, электронная почта, телефон) в **Firebase Firestore**. Возможность редактирования данных в реальном времени.
- **🌍 Мультиязычность**: Полная поддержка трех языков — **Русского**, **Арабского** и **Английского**. Поддержка RTL (справа налево) для арабского языка и сохранение выбранного языка при перезапуске.
- **🤖 Анализ на основе ИИ**:
  - **Классификация опухолей**: Определение типа (Доброкачественная, Злокачественная или Норма).
  - **Сегментация**: Выделение точной области опухоли на снимке с наложением маски.

## 🧠 Интегрированные модели ИИ (TFLite)
Приложение использует две оптимизированные модели TensorFlow Lite:
1. **Модель классификации (`breast_classification_model.tflite`)**:
   - Принимает на вход снимок УЗИ.
   - Выдает вероятность для трех классов: Доброкачественная (0), Злокачественная (1), Норма (2).
2. **Модель сегментации (`breast_segmentation_model.tflite`)**:
   - Генерирует попиксельную маску опухоли.
   - Программное наложение маски на исходное изображение для визуализации области поражения.

## 🏗️ Архитектура и технологии
Проект построен с использованием современных стандартов разработки мобильных приложений:
- **Clean Architecture (Чистая архитектура)**: Разделение на слои (Data, Logic, UI) для масштабируемости и чистоты кода.
- **State Management (BLoC/Cubit)**: Использование библиотеки `flutter_bloc` для управления состоянием приложения и логикой локализации.
- **Dependency Injection (GetIt)**: Централизованное управление зависимостями для сервисов и репозиториев.
- **UI/UX**: Использование `flutter_screenutil` для адаптивности под любые экраны и современных стилей для премиального внешнего вида.

# [العربية] - الوصف التقني للمشروع

هذا الدليل مخصص للاستخدام في الأبحاث العلمية والعروض التقديمية، حيث يوضح بالتفصيل إمكانيات التطبيق، بنيته التحتية، وتعامل الذكاء الاصطناعي مع البيانات.

## 🌟 المميزات الرئيسية
- **🔐 المصادقة الآمنة**: دمج **Firebase Auth** لعمليات تسجيل الدخول وإنشاء الحسابات بشكل آمن.
- **👤 إدارة الملف الشخصي**: تخزين بيانات المستخدم (الاسم، البريد الإلكتروني، الهاتف) في **Firebase Firestore** مع إمكانية التعديل المباشر.
- **🌍 دعم اللغات المتعددة**: دعم كامل لثلاث لغات — **العربية**، **الروسية**، و **الإنجليزية**. دعم شامل لواجهات RTL (من اليمين لليسار) وحفظ خيارات اللغة المفضلة.
- **🤖 التحليل بالذكاء الاصطناعي**:
  - **تصنيف الأورام**: تحديد نوع الورم (حميد، خبيث، أو طبيعي).
  - **تجزئة الصور (Segmentation)**: تحديد منطقة الورم بدقة على الصورة مع عرض قناع مرئي (Mask Overlays).

## 🧠 نماذج الذكاء الاصطناعي (TFLite)
يعتمد التطبيق على نموذجين مُحسنين من TensorFlow Lite:
1. **نموذج التصنيف (`breast_classification_model.tflite`)**:
   - يقوم بتحليل صور الأشعة (Ultrasound).
   - يعطي النتائج لثلاث فئات: حميد (0)، خبيث (1)، طبيعي (2).
2. **نموذج التجزئة (`breast_segmentation_model.tflite`)**:
   - يقوم بإنشاء قناع بكسلي دقيق يحدد مكان الورم.
   - دمج القناع برمجياً فوق الصورة الأصلية لتوضيح المصاب للمستخدم.

## 🏗️ البنية التحتية والتقنيات المستخدمة
تم بناء المشروع وفقاً لأحدث معايير تطوير التطبيقات:
- **Clean Architecture**: فصل الطبقات (البيانات، المنطق، الواجهات) لضمان سهولة التوسع وصيانة الكود.
- **إدارة الحالة (BLoC/Cubit)**: استخدام مكتبة `flutter_bloc` لإدارة حالة التطبيق ومنطق تغيير اللغات.
- **حقن التبعيات (GetIt)**: إدارة مركزية للخدمات والمستودعات (Repositories).
- **تجربة المستخدم (UI/UX)**: استخدام `flutter_screenutil` لضمان ملاءمة الواجهات لجميع أحجام الشاشات مع تصميم عصري واحترافي.
