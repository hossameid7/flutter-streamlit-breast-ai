# Data Specification

## 1. Источник данных (Data Source)
* **Датасет:** Breast Ultrasound Images Dataset (BUSI).
* **Источник:** Kaggle.
* **Ссылка:** [BUSI Dataset на Kaggle](https://www.kaggle.com/datasets/sabahesaraki/breast-ultrasound-images-dataset/data)
* **Формат:** PNG изображения.
* **Объем:** 780 снимков (оригинальное разрешение ~500×500 пикселей).

## 2. Схема и Разметка (Annotation)
* **Классификация (3 класса):** - `benign` (доброкачественная опухоль)
  - `malignant` (злокачественная опухоль)
  - `normal` (норма, отсутствие патологий)
* **Сегментация:** К каждому снимку (для классов benign и malignant) прилагаются Ground Truth бинарные маски, точно выделяющие контур опухоли.

## 3. Проверки и контракты (Data Checks / Validation)
* **Формат:** Система API принимает только файлы `image/jpeg` и `image/png`.
* **Разрешение:** Минимально допустимое разрешение снимка перед инференсом: `256x256`. Если меньше — выдается ошибка.
* **Fail-Fast (Out-of-Domain):** Если на вход подается изображение, не являющееся медицинским снимком (шум, случайное фото), система отбраковывает его (Data Contract Violation) до начала работы тяжелых моделей.
