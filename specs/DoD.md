# Definition of Done (DoD)

**Критерии готовности ML-фичи к релизу (проверяемая процедура):**

1. **Данные проверены:** Датасет BUSI загружен, проверен на дубликаты, дисбаланс классов учтен при обучении.
2. **Пайплайны зафиксированы:** Ноутбуки `breast-classification.ipynb` и `breast-segmentation.ipynb` отработали без сбоев.
3. **Eval-gates пройдены:** Метрика Recall для класса `malignant` (злокачественная) составляет строго **>= 0.95**.
4. **Артефакты сохранены:** Модели `.keras` (для Streamlit) и `.tflite` (для Flutter) выгружены в директорию `/reports/models`.
5. **Data Tests внедрены:** API Streamlit проверяет формат и размер входящего изображения (Fail-Fast).
6. **Тесты кода пройдены:** Flutter приложение компилируется без ошибок (Zero build errors).
7. **Интеграция проверена:** Мобильное приложение успешно отправляет снимок на сервер Streamlit и корректно отображает полученную маску сегментации (Overlay).
8. **Безопасность (Safety):** Система умеет отвечать "Не уверен" (Low Confidence) вместо случайных предсказаний, отправляя снимок на ручную проверку врачу.
9. **Мониторинг описан:** В Flutter внедрен Firebase Crashlytics для отслеживания падений, а на сервере логируются таймауты и ошибки 500.
10. **Rollback (План отката) описан:** В приложении предусмотрен флаг (Kill Switch), отключающий ML-анализ и возвращающий интерфейс к простой базе данных пациентов в случае деградации API.
11. **Владелец назначен:** Эид Хоссам отвечает за ML-модели и пайплайны, Зарипов Рамиль — за Flutter-клиент.
12. **Документация готова:** Оглавления PRD и Data Spec заполнены в папке `/specs`.

## Перечень артефактов и тестов для кейса

**Артефакты (Artifacts):**
1. Скрипты обучения: `/pipelines/breast-classification.ipynb` и `breast-segmentation.ipynb`.
2. Веса для API: `breast_classification_model.keras`, `final_breast_seg_model.keras`.
3. Веса для Edge-устройств: `breast_classification_model.tflite`, `breast_segmentation_model.tflite`.
4. Сборка мобильного клиента: `app-release.apk`.
5. Набор спецификаций: `/specs/PRD.md`, `/specs/Data_Spec.md`, `/specs/DoD.md`.

**Тесты (Tests):**
1. **Behavioral Tests:** Модель протестирована на 15 контрольных снимках (по 5 для benign, malignant, normal) из `/tests/test_images/`.
2. **Data Validation Tests:** Скрипт проверки отбрасывает файлы неверного формата (например, .txt или поврежденные картинки).
3. **E2E UI Tests:** Проверка флоу в приложении от экрана входа (Firebase Auth) до получения результатов инференса.
